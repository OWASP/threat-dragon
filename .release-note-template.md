### Source code

The source code is available as a [.tar.gz file][tar] or a [.zip file][zip].

### Docker containers

Production images are available from [Docker Hub][docker].
The `vX.Y.Z` and `stable` tags support AMD64 and ARM64.
The `vX.Y.Z-arm64` tag remains for backward compatibility.

```bash
docker pull owasp/threat-dragon:v2.x.x
```

#### Install on Windows

Download and run the NSIS installer.
Your Windows security settings might require you to select **Unblock** in the file properties.

#### Install on macOS

Download and open the DMG for your processor.
The macOS ZIP files are for Electron's automatic updates; they are not intended for manual installation.

#### Install on Linux

Use the package for your Linux distribution:

- Use the AppImage on most Linux distributions.
- Install the Snap from [Snapcraft][snap].
- Use the RPM on Red Hat Enterprise Linux, CentOS, Fedora, and compatible distributions.
- Use the DEB on Debian, Ubuntu, and compatible distributions.

### Software bills of materials

The release includes a [combined SBOM bundle][sboms], a [server SBOM bundle][server], and a
[container application SBOM bundle][container]. Each bundle contains CycloneDX JSON and XML documents.

### Verify release artifacts

The Linux packages, Snap package, and Docker images have SLSA Build Level 2 provenance.
Verify a downloaded file or the production image with GitHub CLI:

```bash
gh attestation verify Threat-Dragon-ng-2.x.x.AppImage --repo OWASP/threat-dragon
gh attestation verify oci://docker.io/owasp/threat-dragon:v2.x.x --repo OWASP/threat-dragon --bundle-from-oci
```

The signed Windows and macOS files do not have SLSA Build Level 2 provenance.
Threat Dragon's maintainers use [Certum's](https://certum.store/open-source-code-signing-on-simplysign.html) 
open source signing certificates, which are not supported in GitHub Actions. The Windows and MacOS
binaries are signed offline, and the Electron updater metadata are generated after signing.

The immutable release attestation covers the final published assets.
Verify the release and a downloaded asset with GitHub CLI:

```bash
gh release verify v2.x.x --repo OWASP/threat-dragon
gh release verify-asset v2.x.x <downloaded-file> --repo OWASP/threat-dragon
```
